# اطلس کرج | Karaj Atlas

**اطلس جامع، دقیق و آفلاین‌محور کرج** — پروژه‌ای برای نمایش نقشهٔ شهری، ساختمان‌ها، راه‌ها، مکان‌های مهم و داده‌های تاریخی با ذکر منبع و سطح اطمینان.

> وضعیت فعلی: اسکلت مستندات پروژه. هنوز دادهٔ کامل شهر، بستهٔ آفلاین یا نقشهٔ نهایی تولید نشده است.

## اصول داده
- هر داده باید منبع، تاریخ دریافت، مجوز و روش تولید داشته باشد.
- دادهٔ اندازه‌گیری‌شده از دادهٔ تخمینی جدا نمایش داده می‌شود.
- ارتفاع ساختمان فقط در صورت وجود تگ معتبر ثبت می‌شود؛ مقدار تخمینی باید با برچسب «تخمینی» باشد.
- اطلاعات تاریخی مسجد و بناها با تفکیک تاریخ تأسیس، ساخت، افتتاح و مرمت ثبت می‌شود.
- محدودهٔ شهر و محله‌ها باید بر اساس مرجع معتبر و نسخه‌دار تعیین شود؛ مرزبندی‌های نامطمئن با قطعیت کاذب منتشر نمی‌شوند.

## فناوری هدف
- MapLibre GL JS برای نمایش نقشه
- PMTiles برای بسته‌بندی کاشی‌ها و استفادهٔ آفلاین
- دادهٔ OpenStreetMap با رعایت ODbL و انتساب مناسب
- رابط فارسی و راست‌به‌چپ، جست‌وجو، لایه‌ها، فیلتر، نشانک و کارت اطلاعات

## نقشهٔ راه
1. تعریف مدل داده و ثبت منابع
2. تعیین محدودهٔ مطالعه و تهیهٔ دادهٔ خام
3. پاک‌سازی، اعتبارسنجی و ساخت کاشی‌های برداری
4. رابط نقشه و جست‌وجوی فارسی
5. مدل سه‌بعدی ساختمان‌ها و ارتفاع‌های مستند
6. لایهٔ مکان‌های مهم و داده‌های تاریخی
7. بسته‌بندی ویندوز و آزمون کاملاً آفلاین

## مشارکت و کیفیت
قبل از انتشار هر لایه، پوشش، تازگی، صحت هندسی، مجوز و منشأ آن بررسی می‌شود. این مخزن فعلاً ادعای پوشش کامل یا صحت صددرصدی داده‌های کرج ندارد.
