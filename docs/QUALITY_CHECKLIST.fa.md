# چک‌لیست کیفیت اطلس

- [ ] مرز شهر و محدودهٔ مطالعه با منبع و تاریخ روشن
- [ ] ثبت تاریخ دانلود، نسخه و checksum داده
- [ ] ثبت مجوز و انتساب هر لایه
- [ ] بررسی هندسه‌های خراب، تکراری و خارج محدوده
- [ ] بررسی فارسی/عربی/Unicode و نام‌های جایگزین
- [ ] ارتفاع ساختمان فقط از منبع معتبر؛ تخمین جدا و آشکار
- [ ] POIها دسته‌بندی و منبع‌دار
- [ ] دادهٔ تاریخی با چند منبع و سطح قطعیت
- [ ] نمایش هشدار برای لایهٔ ناقص/قدیمی
- [ ] آزمون مرورگر و دستگاه کم‌توان
- [ ] آزمون آفلاین کامل (قطع شبکه)
- [ ] ثبت باگ‌ها و محدودیت‌های پوشش
